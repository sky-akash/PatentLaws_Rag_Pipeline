3.3 Errors in the search report 

If an editorial error is found in a search report before it has been published, a new search report will be drawn up to replace it. Where the search report has already been sent to the applicant in accordance with Rule 65 but has not yet been published, the applicant is notified of the error immediately. If a serious error is discovered after publication, a corrigendum is published in the European Patent Bulletin, and the applicant and the examining division are informed accordingly. If a different document from the one cited has been made available to the applicant by mistake, the right one is made available.
