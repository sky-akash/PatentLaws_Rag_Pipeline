5.1 Page‑setting 

As far as possible all figures of the drawings should be set out upright on the sheetspage. If a figure is broader than it is high, it may be set out so that the top and bottom of the figure lie along the sides of the sheet page with the top of the figure on the left side of the sheetpage.

In this case, if other figures are drawn on the same sheetpage, they should be set out in the same way, so that all the figures on a single sheet page lie along parallel axes.

Where the sheet page has to be turned in order to read the figures, the numbering should appear on the right-hand side of the sheetpage.
