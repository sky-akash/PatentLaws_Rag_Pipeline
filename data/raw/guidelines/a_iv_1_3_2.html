1.3.2 Request for grant 

The request for grant of a patent must contain a statement that a divisional application is sought and state the number of the parent application. It should also mention which generation of divisional application is being filed (Rule 38(4), Art. 2(1), item 1b, RFees). If the request is deficient, as can arise if there is no indication that the application constitutes a divisional application, even though some of the accompanying documents contain an indication to that effect or if the number is missing, the deficiency may be corrected in the manner indicated in A‑III, 16 or under Rule 139 (see A‑V, 3).
