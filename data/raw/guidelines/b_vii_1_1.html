1.1 Partial European search report 

If the search division considers that a European patent application lacks unity of invention (see F‑V, 1), it must carry out a search, and draw up a partial European search report under Rule 64(1), for those parts which relate to the invention (or unitary group of inventions) first mentioned in the claims (see F‑V, 3.4). The partial European search report is accompanied by a list of the separate inventions identified.

For more on the search opinion in cases where there is a lack of unity of invention, see B‑XI, 5.
