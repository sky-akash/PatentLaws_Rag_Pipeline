7.3.3 Matters to be determined by the division in cases of oral description 

Once again, the following details will have to be determined:

(i)when the oral description took place 

(ii)what was orally described and 

(iii)whether the oral description was made available to the public; this will also depend on the type of oral description (conversation, lecture) and on the place where it was given (public meeting, factory hall; see also G‑IV, 7.2(iii)).
